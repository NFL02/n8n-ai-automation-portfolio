# 🤖 محفظة مشاريع الأتمتة والذكاء الاصطناعي | AI & Automation Portfolio

مجموعة من مشاريع الأتمتة الذكية المبنية باستخدام **n8n**، تجمع بين الأتمتة الكلاسيكية والذكاء الاصطناعي التوليدي (Generative AI) لحل مشاكل حقيقية في الأعمال الصغيرة والمتوسطة.

A collection of intelligent automation projects built with **n8n**, combining classic workflow automation with generative AI to solve real business problems for small and medium enterprises.

---

## 📂 المشاريع | Projects

### 1️⃣ نظام تذكير مواعيد ذكي | Smart Appointment Reminder System
أتمتة تُرسل تذكيرات WhatsApp تلقائية للعملاء قبل مواعيدهم، مع تحديث حالة الإرسال لمنع التكرار.

Automated workflow that sends WhatsApp reminders to customers before their appointments, with status tracking to prevent duplicates.

**التقنيات | Tech:** n8n, Google Sheets, Schedule Trigger, JavaScript

---

### 2️⃣ وكيل حجز ذكي بالذكاء الاصطناعي | AI-Powered Booking Agent
وكيل محادثة ذكي يتفاعل مع العملاء بالعربية لحجز المواعيد، مع التحقق من التعارضات، معرفة الأسعار الديناميكية، وتعديل/إلغاء الحجوزات - متاح عبر واجهة ويب مباشرة.

Conversational AI agent that handles appointment booking in Arabic, checks for scheduling conflicts, provides dynamic pricing, and manages booking modifications/cancellations - accessible via a live web interface.

**التقنيات | Tech:** n8n AI Agent, Google Gemini, Memory, Multiple Tools, Chat Widget

---

### 3️⃣ وكيل بحث متعدد المصادر (MCP) | Multi-Source Research Agent (MCP)
وكيل ذكاء اصطناعي متصل بخوادم MCP خارجية (Model Context Protocol) للبحث في الإنترنت وقراءة توثيق مشاريع GitHub تلقائياً.

AI agent connected to external MCP (Model Context Protocol) servers for web search and automatic GitHub documentation analysis.

**التقنيات | Tech:** n8n, MCP Client Tool, Google Gemini

---

### 4️⃣ قارئ فواتير ذكي | Smart Invoice Reader
نظام يستخرج بيانات منظمة (المورد، التاريخ، المبلغ، المنتجات) من صور الفواتير تلقائياً باستخدام الذكاء الاصطناعي متعدد الوسائط (Vision AI)، ويحفظها في قاعدة بيانات منظمة.

System that automatically extracts structured data (supplier, date, total, products) from invoice images using multimodal Vision AI, saving results into a structured database.

**التقنيات | Tech:** n8n, Google Gemini Vision, JSON Parsing, Google Sheets

---

### 5️⃣ مركز دعم عملاء ذكي متعدد المسارات (RAG) | Multi-Path AI Customer Support Hub
نظام دعم عملاء احترافي بأربعة مسارات متخصصة: أسئلة شائعة عبر RAG وقاعدة بيانات متجهات حقيقية، تتبع حالة الطلبات، تسجيل وتصعيد الشكاوى تلقائياً، وتحليل رضا العملاء.

Professional customer support system with four specialized paths: FAQ answering via RAG with a real vector database, order status tracking, automated complaint logging and escalation, and customer satisfaction analysis.

**التقنيات | Tech:** n8n AI Agent, RAG, Supabase (pgvector), Google Gemini Embeddings, Gmail, Google Sheets
